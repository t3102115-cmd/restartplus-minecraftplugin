# restartplus-minecraftplugin
# This plugin is for Paper created
A Minecraft Server paper plugin that allows Admins to restart and stop the server, for a reason and in a specified time. 
The restart and stop message are gonna be changable in version 1.1. 
Syntax: "/restartplus {time} {reason}" to restart the server in ... seconds for the reason ... 
"/stopplus {time} {reason}" to stop the server in ... seconds for the reason ... 
"/cancelrestart" to cancel a restart "/cancelstop" to cancel a stop
Permissions: "restartplus.use": use the "/restartplus" and the "/cancelrestart" command 
"stopplus.use": use the "/stopplus" and the "/cancelstop" command

IMPORTANT: !!! THE PLUGIN CONTAINS AI GENERATED CODE !!!

How to Download?
1. Go to here: https://github.com/t3102115-cmd/restartplus-minecraftplugin/releases/
2. Download the newest version
3. Put it in your plugins folder
4. Restart the server if its on
5. Have fun :)

To complile the project yourself:
1. Download Maven
2. Put it in yout PATH
3. Download this Project
4. Unzip it using WinRAR or 7zip
5. Open Command Prompt
6. cd into your folder where the project is
7. Run mvn clean package
8. Wait until it finishes
9. Go into your folder in a filemanager where the project is
10. Find the folder "target"
11. Copy the .jar to your plugins folder
12. Restart the server if its on
13. Have fun :)
